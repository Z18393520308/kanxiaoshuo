# Windows 交互验收

自动化测试负责文本解码、位置换算、配置合并/迁移、热键格式与底层窗口操作。以下真实桌面行为仍需在 Windows 10/11 + WebView2 上确认。

## 准备

- 使用发布包，在独立测试账号或备份 `%AppData%\摸鱼联盟` 后测试。
- 准备两本不同 TXT：UTF-8 混合中英文/表情，GBK 中文；另备一个大于 3 MB 的 TXT。
- 测试文字包含短段落、长段落、空行和文件尾不足一页的情况。

## 检查步骤

1. 首次启动并选书，阅读条有字、可拖动、保持置顶；设置关闭后托盘可再次打开。
2. 连续翻过至少 20 页再回翻，跨块处不漏字、不重复卡页、不乱码；到文件尾后仍能返回。
3. 读到包含表情或中英文混排的位置，退出重开后第一行起始文字一致。
4. 在书 A 翻页，打开书 B 翻页，再分别从最近阅读打开 A/B，位置互不覆盖。
5. 隐藏阅读条，在其他软件中使用翻页组合键；阅读进度保持不变；显示后继续阅读。
6. 修改快捷键；填入重复组合应被拒绝。用另一个测试程序占用热键后应用配置，应提示占用并保留可用配置。
7. 修改宽度、字体、字号、行数及字间距（0 / 8 / 20 像素），当前阅读文字位置保持，字距增加后实际换行改变；保存并重启仍保持字距，翻页不漏字。选择接近白色文字后仍可看到。
8. 拖动到副屏并退出重开；关闭副屏后重开/显示，阅读条回到可见区域。验证不同 DPI 显示器。
   将阅读条拖到任务栏区域，松手、隐藏再显示、退出重开均不应弹回任务栏上方；任务栏位于底部、顶部或两侧时分别检查。
9. 移动书 A 的文件，从最近阅读选择重新定位，位置保留；取消选择不改变记录。
10. 从托盘换书、双击托盘、退出；重启 Explorer 后托盘图标恢复；退出后所有热键释放。
11. 重复启动 EXE，提示已有实例，书签文件不会被多实例覆盖。
12. 用旧版 Go 配置打开原小说完成位置迁移；损坏 JSON 应显示错误且不覆盖原文件。
13. 在无 WebView2 环境启动，显示运行时安装指引。
