# 摸鱼联盟 0.2.1 使用说明

## 安装与启动

1. 从 [v0.2.1 发布页](https://github.com/Z18393520308/kanxiaoshuo/releases/tag/v0.2.1) 下载 Windows x64 ZIP，解压到一个固定目录。
2. 运行 `摸鱼联盟.exe`，无需安装 .NET。
3. 点击右侧「浏览」选择 TXT，在「阅读样式」中设置字号、颜色、行数和字间距。展开下方「更多设置」可调整字体与宽度，然后点击「保存并开始阅读」。
4. 按住阅读条拖动，松开后保存窗口位置。

系统要求 Windows 10 / 11 x64 与 Microsoft Edge WebView2 Runtime。如果启动提示缺少 WebView2，请从微软官网下载 Evergreen Runtime 并安装：
https://developer.microsoft.com/microsoft-edge/webview2/

## 托盘与设置

在任务栏通知区域找到摸鱼联盟图标（可能在折叠区内）。右键菜单可显示/隐藏阅读条、打开设置、换书、退出。退出会保存进度。设置窗关闭后，可通过托盘重新打开。

## 快捷键

| 默认按键 | 功能 |
| --- | --- |
| Alt + ↑ | 上一页 |
| Alt + ↓ | 下一页 |
| Alt + C | 隐藏阅读条 |
| Alt + S | 显示阅读条 |
| Alt + T | 复位位置 |

在设置页修改快捷键；示例 `Ctrl+Alt+Up`、`Alt+PageDown`。重复组合或已被其他程序占用时会提示错误。隐藏时翻页热键释放给其他程序，显示时重新注册。阅读条会自动选择与文字不同的透明底色，黑色和白色文字均可使用。

## 书籍与进度

每本书独立记忆位置。设置页下方的「最近阅读」折叠区保存最多 30 本，展开后点击可恢复阅读。书籍移动后，在缺失项目中重新选择文件即可保留旧位置。请重新选择同一本书；如果选择内容不同的文件，原偏移不再代表相同文字。

支持 UTF-8、GBK、带 BOM 的 UTF-16 LE/BE。读取时会规范化换行。更改小说文件内容后，原阅读位置可能发生变化。

配置位置：`%AppData%\摸鱼联盟\config.json`。升级时直接替换 EXE，保留该目录即可继续使用原配置。旧 Go 版位置会在首次成功打开该书时迁移；旧版进度本身采用估算值，迁移无法恢复旧版已丢失的精确位置。

## 显示与窗口

支持宽度 240–1600 像素、1–15 行、字号 3–48、字间距 0–20 像素，以及自定义字体和颜色。字间距为 0 时使用字体默认间距；修改后先预览，再点击保存，实际阅读条会按新字距折行并保留当前书签。

阅读条可拖到任务栏区域，退出后保留位置；仅超出完整屏幕或原显示器断开时，程序才将它调整到可见屏幕。找不到阅读条时可按 `Alt+S`，再按 `Alt+T`。

## 完整性检查

发布包中的 `SHA256SUMS.txt` 记录 EXE 校验值。PowerShell 可运行：

```powershell
Get-FileHash .\摸鱼联盟.exe -Algorithm SHA256
```

对比输出与文件中的 SHA-256。程序尚未使用代码签名证书签名。
