## 已覆盖的关键回归

- GBK 中文、UTF-8/BOM、UTF-16 LE/BE 和表情解码。
- CRLF 段落保留、NUL 处理、UTF-16 控件位置到 UTF-8 字节书签转换。
- UTF-8 字符边界分块和旧版 rune/字节索引迁移。
- 不覆盖最新进度的偏好保存、并发历史更新、30 本上限、损坏配置保护。
- 热键别名、重复组合、保存失败回滚、同路径重定位后显式恢复进度。
