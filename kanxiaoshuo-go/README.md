# 摸鱼联盟（Go 版）

原 [摸鱼联盟](../README.md) WPF 项目的 **Go 重写**：单文件 exe、无需 .NET，适合 Windows 10/11 上边工作边读 TXT 小说。

## 功能概览

| 模块 | 说明 |
|------|------|
| 配置界面 | WebView2 极简 UI：选书、字号、颜色、可见行数 |
| 阅读条 | 置顶细条窗口，**背景透明**、**文字不透明** |
| 大文件 | 全书进内存，按块加载约 5 折行，块末/块首自动预读 |
| 交互 | 只读、不可选中文字、无边框、**按住左键拖动** |
| 热键 | 全局快捷键翻页、显示/隐藏、复位位置 |

## 快捷键

| 按键 | 作用 |
|------|------|
| `↑` | 向上翻页（步长 = 可见行数） |
| `↓` | 向下翻页 |
| `Alt+C` | 隐藏阅读条 |
| `Alt+S` | 显示阅读条 |
| `Alt+T` | 阅读条移到屏幕 (100, 100) |

阅读条上 **按住左键拖动** 可改变位置。

## 环境要求

- **Windows 10 / 11**（x64）
- [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)（系统通常已预装）
- 编译时需 [Go 1.21+](https://go.dev/dl/)

```powershell
winget install GoLang.Go
```

## 快速开始

### 使用已编译的 exe

1. 运行 `摸鱼联盟.exe`
2. 在配置窗选择 TXT，调整字号、颜色、**显示行数**（1–10）
3. 点击保存，配置窗隐藏，出现阅读条
4. 用 `↑` / `↓` 阅读，`Alt+C` 临时隐藏

### 自行编译

```powershell
cd kanxiaoshuo-go
go mod tidy
go build -ldflags="-s -w -H windowsgui" -o 摸鱼联盟.exe .
```

或双击 `build.bat`。

生成约 **6–8 MB** 的单个 exe（无控制台窗口），无需附带其他 DLL 或 .NET。

## 配置说明

首次保存后，配置写入：

```
%AppData%\摸鱼联盟\config.json
```

主要字段：

| 字段 | 含义 |
|------|------|
| `book_path` | TXT 路径 |
| `char_index` | 阅读位置（字符下标，书签） |
| `font_size` | 字号（随可见行数有上限） |
| `font_color` | 颜色，如 `#000000`（勿用纯白，会与透明底冲突） |
| `visible_lines` | 阅读条同时显示的行数（1–10） |
| `window_left` / `window_top` | 窗口位置 |

旧版 `line_index` 仍可读，首次会粗略换算为 `char_index`。

## 技术说明

### 阅读条为何不用分层自绘

早期版本用 `UpdateLayeredWindow` 自绘透明条，在部分环境下会出现「窗口存在但完全看不见」。当前实现为：

- 父窗口：**色键透明**（纯白 `#FFFFFF` 变透明）
- 子控件：标准 **只读 EDIT**，白底 + 配置字体色
- 子类处理：禁止输入/粘贴/选中，左键转发为拖动

### 大文件策略

- 小于约 **3MB**：全文转为 `[]rune`，按字符书签
- 更大文件：保留 `string`，按 UTF-8 字节分块，避免内存翻倍
- 每次向控件装入约 **5 折行** 原文；滚到块末再加载下一块（后台预读上下块）

## 常见问题

**保存后看不到阅读条？**

- 按 `Alt+S` 显示；按 `Alt+T` 移到屏幕中央附近
- 确认字体颜色不是白色
- 确认已安装 WebView2

**大 TXT 打开慢？**

- 首次需读入全文到内存，体积越大越久；之后翻页走分块，会流畅很多

**想恢复透明摸鱼外观？**

- 当前为「白底色键透明 + 实色字」，已兼顾可见性与摸鱼；完全透明底可在此基础上再调
